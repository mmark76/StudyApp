# StudyApp v1.5.16 release scope

This release adds a local-only Writer & Translator entry to the Workspace Tools panel. In StudyApp Local settings, the user supplies the folder of a separately maintained Writer application; the tool asks for confirmation and requests its launch. The Web/PWA edition displays the tool as unavailable, because it cannot start local programs. No study material is sent or copied to the Writer automatically.

The local companion checks the request origin, confirmation, absolute folder, expected files and resolved entry-point containment; it starts Python using an argument list without a shell. Users should select only trusted application folders. The response confirms a start request, not that the Writer opened successfully. The Writer requires its own Python environment and optional model packages.

This release does not modify study data or storage schema. The Writer is a separate prototype; its model quality and release-readiness conditions remain open. The addition has focused tests and does not claim a comprehensive security assessment.
