# StudyApp v1.5.4 release scope

Source: reviewed PR #340 on main, following the published v1.5.3 release.
This compatible patch refines the active Workspace BETA controls and guidance
without changing stored data, AI transport or Local integrations.

## Changes

- Make the Sources and Structured Study actions clearer: create or open the
  Library, manually structure imported files, use the local Split PDF Tool, or
  see the explicitly unavailable AI-Assisted Structuring path.
- Keep short bilingual guidance on the AI connection and AI-assisted tool
  cards, including the Local-only ChatGPT RAG wording, without activating a
  coming-soon mode.
- Preserve compact, aligned three-panel headers and the lower AI Agent bar's
  truthful Local-only availability state.
- Verify the Progress route by its actual Workspace content, including backup
  and restore controls, rather than by an obsolete card label.

## Compatibility and boundaries

- IndexedDB schemas, stored content, backup/restore and archive formats are
  unchanged.
- ChatGPT authentication, API transport, `store:false`, PDF RAG, attachments,
  consent and privacy mechanisms are unchanged.
- No new AI processing is introduced. AI-Assisted Structuring and future
  AI-Assisted Tools processing remain planned and unavailable.
- Automated Local tests use mocked loopback responses. A real Windows Local
  installation and ChatGPT account still require the documented manual release
  verification.
