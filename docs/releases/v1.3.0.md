# StudyApp v1.3.0 release scope

Source: PR #323, based on the published v1.2.8 release. PR #322 (Model Selector) is outside this release.

## Changes

- Add Summary and Main Points as the first Practice & Mastery action, with Flashcards, Review, Quiz and Progress renumbered 2–5.
- Create, edit, save and download summaries with source references from selected local study files or existing practice-chapter summary points.
- In StudyApp Local, generate an editable AI draft from displayed excerpts only after explicit approval. The browser/PWA offers manual creation without remote AI.
- Store saved results as TXT files in the existing IndexedDB study-files table and Library summary category. The JSON backup does not include these file blobs.

## Review boundaries

- AI-generated text and references require user review. For long files, the request contains at most six sampled excerpts, not the complete file.
- No real OAuth credentials were used in automated tests.
- OpenAI's Cookbook includes personal projects that run locally. The owner has not confirmed separate OpenAI approval for public distribution of StudyApp Local; clarify this point independently. This release does not claim OpenAI endorsement.
