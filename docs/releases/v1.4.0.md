# StudyApp v1.4.0 release scope

Source: reviewed PR #327 on main, following PR #322 (Model Selector) and PR #328 (Windows Local action names). This compatible feature release supersedes v1.3.0.

## Changes

- Process every readable part of each selected document for Summary and Main Points, with an initial 50 MB per-file and per-job limit and no excerpt sampling in this workflow.
- Track page, section and chunk coverage, report unreadable or failed sections, and stop AI generation when coverage is incomplete.
- Require explicit consent for multi-request sending, then process every chunk and combine results hierarchically with source references.
- Show bilingual AI Capabilities & Limits in the relevant StudyApp views, including StudyApp and OpenAI limits and unavailable remaining usage information.
- Include the renamed Windows Local launcher actions from PR #328. Targeted AI questions continue to use approved excerpts.

## Review boundaries

- Automated AI tests use mocked responses and no real OAuth credentials. AI output and citations require user review.
- Image-only/scanned pages are reported as unreadable; this release does not add OCR.
- On 2026-11-03, the owner confirmed that public distribution of StudyApp Local was clarified and permitted under OpenAI or applicable official terms. The repository does not contain separate written OpenAI approval and does not claim endorsement.
