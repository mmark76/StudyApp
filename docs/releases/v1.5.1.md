# StudyApp v1.5.1 release scope

Source: reviewed PR #335 on main, following the published v1.5.0 release.
This compatible patch release refines the approved Workspace BETA Phase 1
three-column experience without changing stored data or integrations.

## Changes

- Default the desktop columns to Sources 25%, Workspace 50% and Tools 25%,
  with two mouse- and keyboard-resizable vertical dividers.
- Split the central Workspace into a 75% upper work region and a 25% lower
  AI Agent region, with an independently resizable horizontal divider.
- Keep the Agent bar visible, show Available only for an authorized Local
  connection, and otherwise show Not available without adding Web/PWA chat.
- Keep the only show/hide icon on the Agent bar and preserve active work and
  Local conversation state when its content is collapsed.
- Align all three panel headers, enlarge the AI option cards, restore the
  existing StudyApp avatar above the right-side tools and improve dark-mode
  contrast for cards, selections, statuses and disabled states.
- Open the existing Library, Manual Import and Split PDF workflows from the
  Sources panel in the centered accessible modal. Right-side tools continue to
  open in the upper central Workspace.
- Extend regression coverage for layout geometry, movable dividers, source
  modals, Agent availability and collapse, active-work preservation, bilingual
  responsive layouts, Local typography and dark-mode contrast.

## Compatibility and boundaries

- IndexedDB schemas, stored content, backup/restore and archive formats are
  unchanged.
- ChatGPT authentication, API transport, `store:false`, PDF RAG, attachments,
  consent and privacy mechanisms are unchanged.
- No new AI processing is introduced. AI-Assisted Structuring and future
  AI-Assisted Tools processing remain planned and unavailable.
- Automated Local tests use mocked loopback responses. A real Windows Local
  installation and ChatGPT account still require the documented manual release
  verification.
