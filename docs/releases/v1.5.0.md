# StudyApp v1.5.0 release scope

Source: reviewed PR #333 on main, following the published v1.4.1 release.
This compatible feature release introduces the approved Workspace BETA Phase 1
three-column experience.

## Changes

- Replace the former four-column Workspace BETA with Sources & Materials,
  AI Studio - Workspace and AI-Assisted Tools while preserving existing routes,
  storage and study workflows.
- Present the four approved AI connection cards and keep ChatGPT-plan
  conversation functionality available only in StudyApp Local Windows.
- Route the eight existing study and practice tools into the central Workspace,
  including the approved Learning Goals, Key Points and Important Terms views.
- Correct hash-route filtering for those three knowledge views and preserve
  active work when changing views or hiding the tools column.
- Align Windows Local chat, model, attachment, PDF RAG, source-review, consent,
  loading, error and status typography with shared Appearance Settings.
- Update regression coverage for desktop, mobile, English, Greek, light/dark
  themes, Local connection states and the three-column layout.

## Review boundaries

- This release does not add AI-Assisted Structuring or new AI-Assisted Tools
  processing. Both remain planned and unavailable.
- IndexedDB schemas, backup/restore formats, archive compatibility, AI transport,
  authentication, `store:false`, consent and privacy boundaries are unchanged.
- Automated Local tests use mocked loopback responses and no real OAuth
  credentials. The packaged Windows launcher and a real ChatGPT account require
  the documented manual release verification.
