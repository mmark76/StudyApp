# StudyApp v1.5.5 release scope

Source: reviewed post-v1.5.4 Workspace BETA presentation updates.
This compatible patch improves card clarity and presentation without changing
stored data, AI transport or Local integrations.

## Changes

- Apply distinct soft card colours to Sources, AI connection and AI-assisted
  tool cards in both light and dark Workspace BETA themes.
- Make card titles slightly more prominent than their supporting explanations,
  while continuing to use the shared appearance and typography tokens.
- Show available connection status in green and unavailable Agent-bar status
  in red, while retaining text labels for accessibility.
- Clarify exactly which local content each tool uses. Summary requires an
  explicit user selection of Library files or practice chapters; nothing is
  selected automatically.
- Keep the detailed Summary workspace hidden on initial Workspace BETA entry
  until the user explicitly chooses to open it.
- Keep only the current Beta ZIP download control visible in Workspace BETA;
  the historical Stable v1.1.5 download remains an existing release asset but
  is no longer presented in the active interface.

## Compatibility and boundaries

- IndexedDB schemas, stored content, backup/restore and archive formats are
  unchanged.
- Direct Local ChatGPT conversation and optional PDF RAG remain independent;
  neither replaces the other. ChatGPT authentication, API transport,
  `store:false`, attachments, consent and privacy mechanisms are unchanged.
- No new AI processing is introduced. The proposed broader modal-only handling
  for existing manual tool mechanisms is not part of this patch.
- Automated Local tests use mocked loopback responses. A real Windows Local
  installation and ChatGPT account still require the documented manual release
  verification.
