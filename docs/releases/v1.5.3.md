# StudyApp v1.5.3 release scope

Source: reviewed PR #339 on main, following the published v1.5.2 release.
This compatible patch corrects the active Workspace BETA AI Assistant handoff
and aligns its regression coverage with the approved panel controls.

## Changes

- Make the available **StudyApp AI Assistant** card a normal user-activated
  external link to the approved dedicated Custom GPT destination.
- Keep concise bilingual descriptions on all four AI option cards without
  activating the coming-soon modes.
- Keep the approved icon-only show/hide control on the AI-Assisted Tools panel
  and verify that hiding either side panel preserves active Workspace content.
- Replace layout-fragile test assertions with stable accessibility-state and
  mounted-content checks.

## Compatibility and boundaries

- IndexedDB schemas, stored study content, backup/restore and archive formats
  are unchanged.
- ChatGPT authentication, API transport, `store:false`, PDF RAG, attachments,
  consent and privacy mechanisms are unchanged.
- The external Assistant link does not read, copy or send StudyApp material;
  no new AI processing is introduced.
- Automated Local tests use mocked loopback responses. A real Windows Local
  installation and ChatGPT account still require the documented manual release
  verification.
