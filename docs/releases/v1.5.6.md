# StudyApp v1.5.6 release scope

Source: reviewed PRs #342 and #343 on main, following the published v1.5.5
release. This compatible patch corrects narrow Sources-panel wrapping and
clarifies the Web/PWA availability state of the persistent AI Agent bar.

## Changes

- Keep Sources & Materials copy readable beside long localized action labels
  in the narrow embedded side panel.
- In the Web/PWA edition, show a second unavailable message beneath the
  persistent AI Agent bar title. It does not appear in StudyApp Local for
  Windows.
- Strengthen the unavailable-state red in light and dark Workspace BETA themes
  while keeping a textual availability label.

## Compatibility and boundaries

- IndexedDB schemas, stored content, backup/restore and archive formats are
  unchanged.
- StudyApp Local chat, ChatGPT authentication and communication, PDF RAG,
  attachments, consent and privacy mechanisms are unchanged.
- No new AI processing is introduced. The Web/PWA edition continues not to
  create an in-app ChatGPT conversation.
- Automated Local tests use mocked loopback responses. A real Windows Local
  installation and ChatGPT account still require the documented manual release
  verification.
