# StudyApp v1.5.7 release scope

Source: reviewed PRs #345 and #346 on main, following the published v1.5.6
release. This compatible patch improves Workspace BETA card appearance, restores
the established Local direct-chat request contract, and pauses RAG while it is
being redesigned.

## Changes

- Apply the approved soft card colours in Workspace BETA while preserving the
  selected appearance settings and contrast rules.
- Restore the v1.1.5-compatible Responses payload for ordinary StudyApp Local
  ChatGPT questions: it keeps the selected model, streaming and `store: false`,
  without sending the later `truncation: disabled` setting.
- Keep the bounded full-document Summary workflow separate, including its
  explicit output bound.
- Temporarily make RAG unavailable in both active and historical Local views:
  attachment, passage-selection and source-review controls are not shown; the
  former passage endpoint rejects requests; English and Greek explain that RAG
  is still under construction.
- Update README, architecture, security, AI-boundary, Workspace BETA, Local
  installation and agent guidance to describe the released behavior.

## Compatibility and boundaries

- IndexedDB schemas, existing study content, backup/restore and archive formats
  are unchanged.
- ChatGPT OAuth, selected-model behavior, streaming, `store: false`, consent
  boundaries, Local packaging and direct conversation remain intact.
- No new remote AI processing, data upload or automated ChatGPT interaction is
  introduced. The Web/PWA edition continues not to create an in-app chat.
- Automated Local tests use mocked loopback responses. A real signed-in Windows
  Local conversation still requires the documented manual release check.
