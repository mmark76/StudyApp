# StudyApp v1.5.2 release scope

Source: reviewed PR #337 on main, following the published v1.5.1 release.
This compatible patch release improves the active Workspace BETA presentation
without exposing the hidden Standard experience or changing stored data and
integrations.

## Changes

- Add an icon-only show/hide control to the Sources panel while keeping the
  upper central Workspace and upper-right Tools panel without collapse controls.
- Preserve active Workspace content when Sources or the lower AI Agent region
  is hidden, and keep the associated dividers keyboard and pointer accessible.
- Label the persistent lower region as an AI Agent bar available only in the
  Local edition, with truthful Available or Not available connection status.
- Make both approved available AI cards selectable. The Web/PWA Local card
  shows a Windows Local notice and installation guide without mounting fake chat.
- Give all eight right-side tool cards distinct soft colors with tested light
  and dark contrast, and label the avatar as AI StudyApp Assistant in a green frame.
- Simplify the BETA-only summary tool wording to Summary of Uploaded Material
  from the left panel while preserving the hidden Standard wording and workflow.
- Extend focused regression coverage for panel state preservation, AI mode
  selection, Standard/BETA separation, bilingual typography and dark contrast.

## Compatibility and boundaries

- IndexedDB schemas, stored content, backup/restore and archive formats are
  unchanged.
- ChatGPT authentication, API transport, `store:false`, PDF RAG, attachments,
  consent and privacy mechanisms are unchanged.
- No new AI processing or automatic Library transfer is introduced.
- Automated Local tests use mocked loopback responses. A real Windows Local
  installation and ChatGPT account still require the documented manual release
  verification.
