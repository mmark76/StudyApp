# StudyApp v1.5.9 stable release scope

Source: reviewed PR #350 on main, following the published v1.5.8 release.
This compatible patch fixes a narrow Workspace BETA layout and unifies the
presentation of tool results and empty states.

The published Web/PWA and Windows Local ZIP assets are labelled **Stable**.

## Changes

- Keep the unavailable AI-Assisted Structuring control fully within its Sources
  card, with wrapping for both English and Greek labels.
- Use the same concise Workspace result presentation for the right-column tool
  empty states, Summary and Progress; large tool surfaces remain out of the
  central result area.

## Compatibility and boundaries

- Existing study, flashcard, review, quiz, summary, progress, backup, restore
  and archive workflows remain intact.
- IndexedDB schemas and stored content are unchanged.
- No AI processing, RAG activation, external data sharing or Local ChatGPT
  behavior change is introduced.
- The Web/PWA edition continues not to create an in-app chat.
